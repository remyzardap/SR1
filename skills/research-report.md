# Research Report with Citations

Use this skill when the user asks a research question that needs a detailed, well-sourced answer.

## Steps

1. Plan 2-4 sub-questions that together answer the main question.
2. Search the web and read full pages for each sub-question.
3. Extract factual claims and their sources.
4. Verify claims against the sources; discard unsupported claims.
5. Write the report in sections with `[n]` citations after every factual claim.
6. Append numbered source cards.

## Output format

- **Summary**: 2-3 sentences.
- **Key findings**: 3-5 bullets with citations.
- **Detailed sections**: as needed (background, analysis, outlook).
- **Sources**: numbered list with title, URL, and date if available.

## Rules

- Every factual claim must have a citation.
- Prefer primary sources and official pages.
- Flag conflicting evidence explicitly.
