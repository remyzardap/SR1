# Sutaeru Quiet canvas (visual target for the next frontend redo)

Twelve phone artboards, 390x844: Home, Home light, Menu, Chat, Voice, Agent working, Agent done, Studio, Docs, Video, Files, You. Same format as `design/sutaeru-canvas`: HTML with inline styles, ignore the `{{...}}` holes and `<sc-for>` template syntax. Layout of the boards is in `canvas.json`.

Images are referenced as `/_blob/<id>` and were not exported with these files. Map them to photos in `client/public/studio/` or export them from the canvas before porting a screen that uses one.

Plan and rules: `docs/spec/FRONTEND-QUIET.md`.
