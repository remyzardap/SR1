# Experiment #1: Obsidian

## Status
**CURRENT IMPLEMENTATION** (backup before Experiment #2)

## Aesthetic
- **Cold, technical, developer-tool feel**
- References: VS Code, Linear, dark-mode SaaS products
- Pure black/gray color scheme
- Generic white accents

## Design Philosophy
- Elevation through shadow (5-level system)
- Glassmorphism (being phased out - 200+ instances)
- Spring physics for natural motion
- High contrast for readability

## Color System
- Base: `#050505` (nearly pure black)
- Text: White hierarchy (`#f2f2f2`, varying opacity)
- Accents: Standard UI colors (teal, amber, rose, blue)

## Components Updated
- ✅ Card component with elevation variants
- ✅ Button component with spring animations
- ✅ Block component with modern interactions
- ✅ Board page with bulk operations

## Pros
- High contrast, very readable
- Familiar to developers
- Safe, won't alienate users
- Works well for complex interfaces

## Cons
- Generic, lacks personality
- Doesn't match Sutaeru's original vision (dark rose + bronze)
- Feels like "another dark mode SaaS"
- Cold rather than elegant/warm
